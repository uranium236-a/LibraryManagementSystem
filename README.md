# LibraryManagementSystem
Implementation of LIbrary Management System CLI in golang

## How to run:
  - Download the main.go file
  - run this commang on terminal: go run main.go

## Functionality:
  - Creates a data storage in json file called library.json
  - Add Book :- Name, Author, Genre, and Rating field are included
  - Remove Book :- Using the ID assigned to each Book
  - Display Book/Books :- Using "all", "name", "author", "genre" commands
